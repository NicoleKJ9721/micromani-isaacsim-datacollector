# 装配物理基础（2026-11-10）

入口：`scripts/open_simulation.sh`，装配层：`outputs/assembly_physics/micromani_assembly.usda`。
构建脚本：`isaacsim_tools/build_assembly_physics.py`（需要 USD、numpy、trimesh）；原始CAD和此前静态场景不修改。保留面包板、双臂与物料台位置，以及三件金腔、三件套筒的初始摆放。

## 零件与接触

- 金腔、套筒分别为独立动态刚体，无抓取焊接、吸附、自动跟随或执行阶段位姿重置。
- 由闭合CAD网格体积和估计密度计算质量、质心与惯量：黄铜8500kg/m³，铝2700kg/m³；金腔约19.56mg，套筒约134.34mg。合金牌号与实测质量未知。
- 夹指移除了URDF导入的父级整件凸包，仅对专用碰撞网格启用SDF（1024），避免凸包填平实际轮廓。夹指传感器初始化也已修复：不能再添加父级凸包，仅订阅已有物理接触。
- 零件原三角网格的稀疏SDF碰撞，保留孔、台阶与缺口。金腔1024、套筒2048分辨率，名义网格间距约2.64/4.39µm。网格间距不是精度保证；CAD三角化、碰撞离散、求解器误差仍影响10µm径向间隙。
- 零件/指体contactOffset=2µm，restOffset=0；不能用默认毫米级接触外扩来代替微小间隙。桌面及其他碰撞体contactOffset=10µm。
- 物理960Hz，TGS求解器32位置/8速度迭代；相机与传感器输出30Hz仿真时间。计算量较大，不保证墙钟实时30FPS。

## TPU夹爪：未知硬度，待标定

用户确认夹爪为3D打印TPU，但硬度、纹路、打印方向未知。
`config/assembly_contact.json`是接触参数源，以下只是仿真初值，不是材料手册数值：

| 接触对 | 有效静摩擦 | 有效动摩擦 |
|---|---:|---:|
| TPU–黄铜 | 0.60 | 0.40 |
| TPU–铝 | 0.65 | 0.40 |
| 黄铜–铝 | 0.39 | 0.25 |

使用multiply组合规则明确计算接触对系数。TPU硬度未知，当前默认使用带独立摩擦参数的刚性接触。刚度10000N/m、阻尼0.1N·s/m的柔顺接触候选值已记录但禁用；早期试验存在父级凸包重复碰撞干扰，不能用这些试验判断柔顺模型有效性。柔顺接触参数仍可调整；**未实现或验证TPU连续体/有限元变形**，不能据此推断真实夹指弯曲、局部压陷或金腔损伤。夹爪驱动当前每指上限：左10mN、右0.5N，见配置中的`gripper_drive_limits_n`。左侧为轻质金腔降低了驱动上限；这是仿真夹具调试参数，不是EPG标定数据，也不等同于指尖法向接触力。

后续标定应使用真实零件做已知夹紧力下的滑移/拉脱实验，并测量指尖挠度；不应仅按“抓住了”反调一个很大的摩擦系数。

## 控制与观测边界

初始化允许设置一次home关节位置；执行阶段只发送物理驱动目标，限速限加速度五次轨迹，不逐步重设位置/清零速度。接口见SIM_API.md。新轨迹在当前运动结束前被拒绝，停止接口清队列并保持当前位置。到达判据是关节反馈；不检测零件真值来宣称抓取、对准或插入成功。

Astra允许的观测是三个相机、关节状态、两路六维力/矩、四指接触力；允许的动作是统一关节/夹爪接口及停止。HTTP接口不返回零件位姿、几何接触点、USD路径或仿真内部刚体状态。六维传感器仍含重力且未去皮，接触判定需基线和坐标变换。

物理QA可在独立夹具中读取真值，以检查场景配置；这些夹具、日志和真值不能作为后续Astra操作的输入。尚未建立操作系统级Astra隔离沙箱。Astra已通过公共接口执行分段观察接近，每段读取图像和力反馈；尚未完成自主抓取/装配验收。本阶段不把夹具试验当作视觉抓取/装配成功。

依据：[NVIDIA碰撞模型文档](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.0/dev_guide/rigid_bodies_articulations/collision.html)、[PhysX材料与柔顺接触参数](https://docs.omniverse.nvidia.com/kit/docs/omni_usd_schema_physics/latest/physxschema/class_physx_schema_physx_material_a_p_i.html)。这些来源说明求解器配置方法，不提供本TPU打印件的实测参数。

## 独立物理QA（不能给Astra调用）

`tests/manual/check_assembly_settling.py` 检查静置漂移；`check_assembly_clearance.py` 检查同轴通过与偏心接触；`check_assembly_grasp.py` 使用实际夹指、独立测试支撑台检查夹持与2mm抬升。它们需要Isaac Python，并可通过 `MICROMANI_QA_OUTPUT` 指定审计目录。抓取夹具用 `FIXTURE_PART=gold_cavity` 或 `sleeve` 选择零件，`TPU_FRICTION_SCALE` 控制摩擦敏感性试验。

夹指专用碰撞网格进行了最长边0.5mm的三角细分，保持CAD曲面原三角面位置，改善小接触区的采样。视觉网格不变。

夹具摆位与一次初始位姿设置只用于物理QA，不属于自主视觉抓取；测量阶段由真实物理关节驱动，没有固定连接、吸附或物体位姿跟随。粗抓取保持判据为2mm抬升期间位移误差小于0.2mm且最终有双指接触，同时单独记录50µm精度指标是否通过；粗保持通过不代表精密对准通过。夹紧后关节未达到更小开口属于正常接触阻挡，需要读传感器，不能把它误报成轨迹到位。

全部 16 个原始关节使用机器人自身模型的重力前馈补偿，避免夹指自重及旋转滑台负载造成恒定跟踪偏差。该范围原先只有四个夹指；右腕向上避让实测出现约 0.000632 rad 的另轴偏差后扩展至全部受控轴，未放宽到位阈值。此补偿不读取零件位置、重量或接触真值；所有姿态下的抓取保持仍未穷举验证。
