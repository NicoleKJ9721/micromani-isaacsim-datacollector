# 独立三路相机窗口

同时显示模型左腕、模型右腕和全局三个实际 RGB 采集通道，不使用 Isaac Sim 的展示相机或截图。独立窗口不会控制机械臂、暂停物理仿真或修改录制数据。

```bash
# 已运行新版 Isaac 启动入口时，仅打开独立窗口：
/home/nkj/Projects/MicroManiURDF/scripts/open_camera_monitor.sh

# 从关闭状态同时启动仿真及独立窗口：
/home/nkj/Projects/MicroManiURDF/scripts/open_simulation_with_monitor.sh
```

三路并排显示；双击任意图像可打开该路放大窗口。暂停显示仅冻结展示，仿真继续运行。显示源渲染时间、实际墙钟更新帧率和三路时间差。暂停仿真或断开后保留最后一帧并明确提示，不伪造更新；仿真恢复后自动继续。

标题区分目标采样频率30 Hz和墙钟显示FPS；相机渲染与夹爪接触按30 Hz仿真时间运行。

默认本机接口 `127.0.0.1:49011/frame`，不对外网开放。窗口自动重连。使用 `MICROMANI_PREVIEW_PORT` 可同时更改启动器和监视器端口。预览为 JPEG（quality=90）、随新源帧逐帧发布（默认30 Hz，不再另设墙钟限帧），只保留最新一组，不积压队列；实际帧率取决于 Isaac 物理计算和渲染性能，不保证实时30 FPS。训练录制仍保留原 PNG、时间戳和采集契约。

窗口左右名称使用模型侧，数值导出的操作者左侧对应模型右侧；标题已标注映射。全局通道是 `/World/global_camera`，不是 `Platform_Overview`。

验证：27项检查通过，包含HTTP等待状态、三路传输、帧递增及停止时不伪造新帧。现场取得序号242→251、三路渲染时间17.800→18.400秒的连续更新；暂停后窗口显示停帧提示。

## 2026-11-10 性能复测

当前装配运行在自由运动阶段使用 120 Hz 物理步长；接近台面、夹爪运动或检测到接触时恢复 960 Hz。相机仍按仿真时间 30 Hz 采样。自由运动期间 12.04 秒墙钟观测得到源帧率 9.97 FPS、仿真速度 0.332 倍，每路 121 个不同渲染时间戳及图像哈希；先前静止测量约 12.68 FPS。此结果不代表接触阶段性能，也不代表已经达到实时 30 FPS。窗口同时显示仿真采样频率、实际新帧率和仿真速度。
